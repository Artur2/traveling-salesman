## Формат export.geojson ##

Данный файл хранит в себе полные маршруты и остановки\
Почему то нет названий у остановок, надо над этим подумать

При процессинге полных путей мы можем смотреть по координатам остановки.\
Это будут наши новые вершины.\
При этом можно получить название остановки по тегу rel.\
Соответственно мы будем вычислять расстояние между остановками как веса.\
Формула для рассчета уже есть
